# Ancillary context module

This module keeps contextual rainfall and Gandak barrage material separate from radar-change inference.

- `extract_august_2026_context.py` — creates official rainfall/discharge context tables.
- `extract_fmisc_gandak_barrage.py` — extracts dated FMISC Gandak report values.
- CSV, JSON, and TSV files — retained derived evidence and provenance.
- `official_august_2026_data_audit.md` — source limits and reproducibility notes.

These files provide context only; they do not confirm the cause of the radar candidate.
