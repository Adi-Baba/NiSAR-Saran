# Quantitative analysis module

- `hotspot_overlay.py` — primary Frequency-B candidate extraction.
- `hotspot-artifacts/` — generated candidate outputs, figures, reports, and figure-generation utilities.
- `results/` — tabular audits and ranked statistical results.
- `rust-workspace/` — tested Rust implementation of audit, distribution, inference, ledger, model, and spatial modules.

Run the primary Python audit from repository root with `bash scripts/run_hotspot_audit.sh`.
