# Hotspot artifacts module

This directory contains reproducible outputs for the selected Frequency-B change candidate.

- `frequencyB_hotspot_summary.*` — selection rule, threshold, location, and statistics.
- `frequencyB_hotspot_points.csv` and `.geojson` — candidate cells for GIS inspection.
- `frequencyB_hotspot_footprint.geojson` — footprint representation.
- `Fig/` — rendered interpretation and quality figures.
- `make_*.py`, `plot_*.py`, and `compute_overlap.py` — optional derived-artifact utilities.
- `hotspot_overlay_report.md` — concise interpretation boundary.
